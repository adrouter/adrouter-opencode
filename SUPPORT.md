# Support

Use [GitHub Issues](https://github.com/adrouter/adrouter-opencode/issues) for reproducible setup,
provider-discovery, transport, or footer problems.

Before opening an issue, record the installed versions without including credentials:

```sh
opencode --version
opencode models adrouter
npm view @adrouter/opencode dist-tags --json
```

Include the operating system, OpenCode version, whether the plugin follows `beta` or `latest`,
the exact sanitized error, and concise reproduction steps. Never post integration keys, prompts,
private response bodies, local paths, environment files, or screenshots containing credentials.

For security-sensitive problems, use the private reporting flow in [SECURITY.md](SECURITY.md).
